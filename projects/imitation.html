01 / v1 Baseline

v1에서는 고정된 조건 10회로 수집부터 실행까지 연결했습니다.

누리 양팔과 2지 그리퍼로 바나나를 집어 트레이에 놓는 Pick & Place를 실험했습니다. 한 팔은 바나나와 트레이를 관측하도록 고정하고, 다른 팔은 VIVE로 교시했습니다. 손목 카메라 2개의 영상을 사용했습니다.

첫 실험인 v1에서는 로봇 시작 자세·바나나 위치와 자세·트레이 위치를 모두 고정하고 10회 교시했습니다. ACT를 학습한 뒤 TCP Relative 설정을 켠 경우와 끈 경우의 실제 로봇 실행을 비교했습니다.

성공하는 경우도 있었지만 실패가 반복됐고, 성공한 동작도 매끄럽지 않았습니다. 이 결과를 출발점으로 삼아, v2에서는 바나나의 위치와 자세에 변화를 주며 수집 범위를 넓혔습니다.

제가 직접 수행한 범위

작업 조건 설정, 교시, 데이터 선별·검증, ACT 학습·추론, 실로봇 실행과 결과 분석을 수행했습니다.

02 / v2 Findings

무작위로 놓다 보니, 같은 조건은 겹치고 빈 조합은 남았습니다.

v2에서는 로봇 시작 자세와 트레이 위치를 유지하고, 바나나의 위치·자세를 무작위로 바꾸어 50회 수집했습니다. v1의 고정된 배치에서 한 걸음 더 나아가, 작업 영역의 다양한 위치에 대응하도록 데이터를 늘렸습니다.

랜덤한 위치에 바나나를 놓더라도 이전과 비슷한 위치나 같은 자세가 반복될 수 있었습니다. 수집 횟수는 늘었지만, 위치와 자세의 다양성이 고르게 확보된 것은 아니었습니다. 이 중복 때문에 데이터 맵에서 충분히 채워지지 않은 위치·자세 조합이 남았을 것으로 판단했습니다.

실행 결과를 위치와 자세로 나누어 보니, 수직 자세에서 특히 ①·④ 위치의 파지가 어려웠습니다. 학습 Loss는 0.0067이었지만 실제 작업에서는 특정 조건의 실패가 남았습니다.

03 / v3 Design

v3에서는 위치·자세를 나누고, 부족한 조건을 더 수집했습니다.

4 × 5 × 480개 기본 조합

트레이 4위치 · 바나나 5위치 · 자세 4종

+ 20회취약 조건 추가 반복

총 100회 교시 수집

트레이와 바나나의 위치를 구분하고, 자세를 수평·수직·좌측 대각·우측 대각의 네 가지로 나누었습니다. 조합별로 수집 여부를 확인해 빈 조건을 채우고, 파지가 어려웠던 위치·자세는 더 반복했습니다.

  1. 시야에 물체와 목적지를 함께 담기

    트레이 위치를 바꾸어도 카메라에 바나나와 트레이가 함께 들어오는지 확인했습니다. 조작 중에는 손목 영상을 보며 가림을 점검했습니다.

  2. 일관된 파지·배치 동작으로 교시

    바나나 중앙을 잡고 천천히 움직였습니다. Pick과 Place에서는 잠시 멈춘 뒤 다음 동작으로 이어지도록 했습니다.

  3. 불안정한 시연은 제외

    덜컹거리거나 멈칫한 Episode는 제외하고 데이터를 선별한 뒤 학습과 실행을 반복했습니다.

05 / Takeaway

버전마다 관찰한 문제를 다음 수집의 기준으로 바꿨습니다.

ENGINEERING NOTE

이번 실험을 통해 모방학습의 성능을 높이려면 모델 학습과 함께 로봇이 어떤 장면과 동작을 경험하게 할지를 설계해야 한다는 점을 배웠습니다. v1의 고정 조건 10회에서 v2의 무작위 50회로 수집 범위를 넓혔지만, 비슷한 위치와 자세가 반복되면서 일부 조합이 충분히 포함되지 않았을 것으로 판단했습니다. 무작위로 배치했다는 사실만으로 작업 영역을 고르게 경험했다고 판단할 수는 없었습니다.

특히 실패가 발생한 위치와 자세를 나누어 살펴보면서, 실패 기록이 다음 실험의 조건을 정하는 근거가 될 수 있음을 느꼈습니다. v3에서는 트레이·바나나 위치와 자세를 조합으로 나누고 취약한 조건을 더 반복했습니다. 또한 카메라에 물체와 목적지가 함께 보이는지, 파지와 배치 동작이 일관되는지, 시연이 끊기지 않는지를 확인하며 데이터의 분포와 품질을 함께 관리했습니다. 이 과정에서 로봇에게 무엇을 보여 주고 어떤 행동을 가르쳤는지 설명할 수 있는 수집 방식이 중요하다고 생각했습니다.

v3의 학습 Loss 0.0037과 실로봇 성공률 90%를 확인하면서, 학습 지표와 작업 수행 결과를 연결해 해석하는 관점도 얻었습니다. 실험의 판단 기준을 학습 완료에 두지 않고, 로봇이 어느 단계에서 멈추거나 파지에 실패하는지까지 관찰해야 개선할 지점이 구체화된다고 느꼈습니다.

앞으로는 학습에 사용하지 않은 위치·자세 조합을 검증 조건으로 정하고, 접근·파지·이송·배치 단계별 실패를 구분해 기록하고 싶습니다. 조명이나 카메라 배치 등 환경 조건도 한 번에 하나씩 바꾸어 성능 변화의 원인을 좁히고, 부족한 조건을 다시 수집하는 순환을 만들고자 합니다. 데이터 수집부터 학습·실행·평가까지 이어지는 과정을 실험으로 관리하며, 새로운 작업에도 적용할 수 있는 모방학습 시스템을 설계하겠습니다.
